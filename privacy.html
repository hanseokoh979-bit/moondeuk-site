[문득]

개인정보처리방침

최종 수정일: 2026년 9월 2일

문득(Moondeuk)은 갤러리 사진에 담긴 촬영 위치를 읽어 여행 지도를 만들고, 그 여행에 노래를 걸어두는 앱입니다. 이 문서는 문득이 무엇을 읽고, 어디에 두고, 언제 기기 밖으로 내보내는지를 빠짐없이 적은 것입니다.

문득은 서버가 없습니다. 개발자는 회원님의 데이터를 한 건도 보관하지 않습니다.

사진 원본은 기기 밖으로 나가지 않습니다. 백업에도 담기지 않습니다.

광고·분석 도구가 없습니다. 어떤 제3자에게도 데이터를 넘기지 않습니다.

데이터가 기기를 떠나는 경우는 딱 셋이고, 아래 3항에 전부 적었습니다.

데이터를 지우고 싶으신가요? 6항에 지우는 방법이 표로 정리되어 있습니다 →

1. 무엇을 읽나요

무엇을어디서왜
촬영 시각, 촬영 위치(GPS), 파일 이름·크기 갤러리 사진의 EXIF 정보 언제 어디에 다녀왔는지를 알아내 지도를 그리기 위해
사진 이미지 갤러리 화면에 보여줄 때만 읽습니다. 복사하거나 따로 저장하지 않습니다
곡 제목과 가수 직접 입력하시거나, 재생 중인 곡에서 여행에 노래를 걸어두기 위해

사진을 옮기거나 지우지 않습니다. 읽기만 합니다.

2. 어디에 저장되나요

기본은 이 기기 안입니다. 앱 내부 저장소에만 저장되며, 다른 앱이 읽을 수 없습니다.

백업을 켜신 경우에만 여행 기록이 회원님 본인의 구글 드라이브에 한 부 더 저장됩니다. 저장 위치는 「앱 데이터 폴더」라는 앱 전용 숨김 영역이라, 드라이브 화면에 보이지 않고 다른 앱이 읽을 수 없습니다. 개발자도 읽을 수 없습니다.

  • 담기는 것 — 여행·도시·노래 연결, 사진을 다시 찾기 위한 참조 키(촬영 시각과 좌표에서 만든 값), 감춘 항목의 표시, 생활권 반경 설정
  • 담기지 않는 것 — 사진 원본

3. 기기 밖으로 나가는 경우 — 셋뿐입니다

① 장소 이름 찾기 (모든 사용자)

좌표만으로는 「부산」인지 「교토」인지 알 수 없어서, 안드로이드 운영체제의 위치 서비스에 대표 좌표를 물어봅니다.

  • 사진 한 장씩 묻지 않습니다. 여행 묶음마다 대표 좌표 한두 개만 묻습니다
  • 사진은 보내지 않습니다
  • 이 처리는 안드로이드가 하며, 구글의 개인정보처리방침을 따릅니다

② 백업 (켜신 경우에만)

2항의 내용이 회원님 본인의 구글 드라이브로 전송됩니다. 여기에는 여행지의 좌표가 포함됩니다. 앱이 드라이브와 직접 주고받으며, 개발자의 서버를 거치지 않습니다.

백업은 기본이 꺼짐이고, 설정 › 데이터 › 백업에서 직접 켜야 동작합니다.

③ 노래를 들으러 갈 때

곡을 누르면 고르신 음악 앱(멜론·유튜브뮤직·스포티파이)이 열립니다. 그때 곡 제목과 가수가 검색어로 그 앱에 전달됩니다. 문득은 음악을 직접 재생하지 않습니다.

위 셋 말고는 아무것도 나가지 않습니다. 개발자의 서버로는 어떤 경우에도 전송되지 않습니다.

4. 알림 접근 권한에 대하여

문득은 「지금 이 노래, 교토에서 들으셨어요」 같은 알림을 위해 알림 접근 권한을 쓸 수 있습니다. 이름이 무서운 권한이라 무엇을 하고 무엇을 안 하는지 분명히 적습니다.

하는 것

  • 지금 재생 중인 곡의 제목과 가수만 읽습니다

하지 않는 것

  • 알림 본문을 한 글자도 읽지 않습니다. 앱의 알림 수신 함수는 비어 있습니다
  • 무엇을 들었는지의 목록·시각·횟수를 남기지 않습니다. 읽은 값은 걸어두신 곡과 맞춰본 뒤 버립니다
  • 아무 데도 전송하지 않습니다

기기에 남는 것은 화면에서 직접 눌러 등록하신 것뿐입니다 — 「같은 곡이에요」로 확인해주신 표기, 「지금 재생 중」에서 눌러 등록하신 곡.

이 권한이 없어도 앱은 정상 동작합니다. 첫 실행에 요청하지 않으며, 설정에서 언제든 끌 수 있습니다.

5. 제3자 제공

없습니다.

  • 광고 SDK, 분석 도구, 크래시 리포터를 넣지 않았습니다
  • 데이터를 판매하거나 공유하지 않습니다
  • 3항의 ①②③ 은 회원님의 기기·계정·고르신 앱으로 가는 것이며, 개발자가 데이터를 넘겨받는 일은 없습니다

6. 보관 기간과 삭제

기기 안의 데이터는 지우실 때까지 보관됩니다. 개발자가 보관하는 데이터가 없으므로 개발자 쪽에서 삭제할 것도 없습니다.

무엇을어떻게
앱 안의 모든 기록설정 › 데이터 › 모든 기록 삭제
드라이브의 백업구글 계정 → 데이터 및 개인 정보 보호 → 앱 데이터
사진 접근 권한시스템 설정 → 앱 → 문득 → 권한
알림 접근 권한시스템 설정 → 알림 접근

앱을 삭제하면 기기 안의 데이터도 함께 삭제됩니다. 드라이브의 백업은 위 방법으로 따로 지워주셔야 합니다.

지우신 뒤에 따로 보관하는 기간은 없습니다. 개발자가 보관하는 데이터 자체가 없어서, 지우면 그 순간 끝입니다. 백업으로 만들어진 사본도 회원님의 드라이브에만 있으므로 그것을 지우시면 남는 것이 없습니다.

8. 아동의 개인정보

문득은 만 13세 미만 아동을 대상으로 하지 않습니다. 아동으로부터 고의로 개인정보를 수집하지 않습니다.

9. 방침이 바뀌면

이 문서를 고치고 최종 수정일을 갱신합니다. 데이터를 다루는 방식이 크게 바뀌는 경우에는 앱 안에서도 알려드립니다.
